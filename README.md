# Firework 🎆

中文 · English · 日本語

## 中文

一个基于 C++ / MFC 的 Windows 烟花小程序项目。

支持放射型、圆环型和双层烟花，可调整颜色、背景、大小与淡出时间；支持保存/打开、撤销/重做，以及带 WAV 音乐或无声的烟花播放。

**使用：** 左键添加烟花，右键删除烟花；通过菜单调整效果和播放设置。

**编译运行**

1. 在 Windows 上安装 Visual Studio 2022，勾选“使用 C++ 的桌面开发”，并安装 MSVC v143、对应的 MFC 组件和 Windows SDK。
2. 打开 `Firework.sln`，选择 `Release | x64`。
3. 生成解决方案，按 `Ctrl + F5` 运行。

**许可证：** [MIT](LICENSE)。

## English

A small Windows fireworks application project built with C++ and MFC.

Create radial, ring, and double-layer fireworks with customizable colors, background, size, and fade duration. Includes save/open, undo/redo, and playback with WAV music or without sound.

**Usage:** Left-click to add a firework and right-click to delete one. Use the menus to adjust effects and playback settings.

**Build and run**

1. On Windows, install Visual Studio 2022 with Desktop development with C++, MSVC v143, the matching MFC components, and a Windows SDK.
2. Open `Firework.sln` and select `Release | x64`.
3. Build the solution and press `Ctrl + F5` to run.

**License:** [MIT](LICENSE).

## 日本語

C++ / MFC で作成した、Windows 向けの小さな花火アプリのプロジェクトです。

放射状・リング状・二重の花火に対応し、色、背景、サイズ、フェード時間を調整できます。保存・読み込み、元に戻す・やり直し、WAV 音楽付きまたは無音での花火再生も可能です。

**使い方：** 左クリックで花火を追加し、右クリックで削除します。効果や再生の設定はメニューから変更できます。

**ビルドと実行**

1. Windows に Visual Studio 2022 をインストールし、「C++ によるデスクトップ開発」、MSVC v143、対応する MFC コンポーネント、Windows SDK を追加します。
2. `Firework.sln` を開き、`Release | x64` を選択します。
3. ソリューションをビルドし、`Ctrl + F5` で実行します。

**ライセンス：** [MIT](LICENSE)。
